# Hochstift Mail/Calendar Agent — Project Home

This is the public project page for a **personal automation agent** used by a
single private user (Rodrigue Scholz). The agent reads and writes only the
owner's own Google Calendar and Gmail mailboxes (personal + a dedicated bot
account) to provide calendar reminders, daily briefings and mail-based
document exchange.

- Operator: private individual, single-user deployment, self-hosted.
- No web service, no data sharing, no third-party access, no analytics.
- OAuth scopes requested are used solely against the operator's own accounts.
- Privacy policy: see [PRIVACY.md](PRIVACY.md).
