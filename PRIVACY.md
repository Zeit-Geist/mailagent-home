# Privacy Policy

This project is a private, single-user automation tool. It accesses Google
Calendar and Gmail data of the **account owner only**, via OAuth 2.0, on a
self-hosted personal server.

- Data is processed exclusively for the account owner.
- No personal data is shared, sold, or transferred to any third party.
- Data is not used for advertising, analytics, or profiling.
- No data leaves the owner's own infrastructure except the direct API calls
  to Google services needed to perform the owner's own requests.
- Access can be revoked at any time by the owner at
  <https://myaccount.google.com/permissions>.

Contact: open an issue in this repository.
